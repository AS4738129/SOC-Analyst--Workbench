# SOC-Analyst-Workbench
Real-world Network Threat Detection Analysis and Incident response | Wazuh | Suricata | Nmap | Nikto | Server | Tailscale

This SOC lab runs entirely on a physical Linux machine, no virtual machines. All security tools (Suricata, Nmap, Nikto, Wazuh) are installed natively. A physical remote server is connected over Tailscale, a WireGuard-based VPN mesh, which provides the network target and generates real traffic for detection and analysis.
